# Jersey Store

Jersey Store is a modern e-commerce front-end for showcasing football jerseys, retro kits, and player-edition collections.

The project currently includes a responsive storefront interface with promotional content and featured product displays. It is built with React and Vite, with a focus on clean presentation and a smooth browsing experience.

## Getting Started

```bash
npm install
npm run dev
```

## Available Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
